# Временный полный доступ на Free

Серверный флаг `FREE_PLAN_TEST_MODE=true` снимает тарифные квоты Free на
контакты, письма, домены и участников во всех рабочих пространствах Free.
Других ограничений функций по тарифу в приложении сейчас нет.
По умолчанию флаг выключен. Цены, подписки, исходные квоты и статистика
использования не изменяются; платные тарифы сохраняют свои лимиты.

Авторизация, роли, изоляция рабочих пространств, блокировка неактивных
подписок, отписки, ограничения скорости отправки, проверка адресатов,
технические лимиты импорта (70 000 контактов, 50 МБ) остаются включёнными.
Ключи внешних сервисов и их ограничения по-прежнему необходимы.
Режим не запускает рассылки сам, но снимает месячную квоту для уже
настроенных отправок Free. SMTP и внешние сервисы могут взимать плату.

## Включение / завершение тестирования

На сервере в `/opt/premium-b2b-mailer/.env` установить
`FREE_PLAN_TEST_MODE=true` для тестирования или `false` для возврата тарифов.
Не изменять остальные переменные и не публиковать содержимое `.env`.
Из каталога приложения применить:

```sh
docker compose -f docker-compose.production.yml up -d --no-deps api worker beat
```

Проверить `/backend-health` через сайт и авторизованный
`GET /api/v1/billing/usage`: во время тестирования Free возвращает
`free_plan_test_mode: true`, `limit: null`, `percent: null` для всех квот.
После выключения возвращаются стандартные квоты: 100 контактов,
500 писем/месяц, 1 домен, 1 участник. Данные сверх лимита не удаляются,
но новые действия, превышающие восстановленную квоту, блокируются.
Перед завершением тестирования согласовать с владельцем работу с базами,
которые уже превышают стандартные лимиты.
