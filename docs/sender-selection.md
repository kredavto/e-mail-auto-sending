# Выбор email отправителя

Откройте **ИИ-помощник → Рассылки и расписание → Новая рассылка**.

В поле **Email отправителя** можно ввести новый адрес или нажать стрелку справа
и выбрать адрес из ранее сохранённых рассылок текущего рабочего пространства.
Повторяющиеся адреса показаны один раз. Клавиши ↑/↓ выбирают адрес, Enter
подставляет его, Escape закрывает список. Выбор не запускает рассылку.

Новый адрес появляется в списке после успешного сохранения черновика рассылки.
Он хранится на сервере в параметрах кампании и доступен после перезагрузки.
Если список не загрузился или пока пуст, адрес можно ввести вручную.

Это выбор заголовка From, а не подключение нового почтового ящика.
SMTP/SES должен разрешать отправку с выбранного адреса. Режим тестовой доставки
Mailpit не изменяется: для внешней отправки по-прежнему нужен настроенный провайдер.

Проверка: `pnpm --dir frontend exec playwright test e2e/sender-email.spec.ts`.
Тест использует имитацию API и не отправляет писем.
