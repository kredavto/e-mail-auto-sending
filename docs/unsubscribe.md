# Автоматическая ссылка отписки

Внизу редактора и HTML-предпросмотра автоматически отображается подчёркнутая ссылка «Отписаться от рассылки» шрифтом 12 px. Вставлять её вручную не нужно. Она добавляется для общих и персонализированных писем, включая старые шаблоны при следующей отправке.

В редакторе, сохранённом шаблоне и скачанном HTML используется безопасная ссылка-пояснение: реальных получателей она не отписывает. Персональная ссылка формируется только при отправке через приложение, отдельно для каждого сообщения. Она также добавляется в текстовую версию письма и служебные заголовки List-Unsubscribe.

Переход по ссылке отправленного письма помечает связанный контакт как отписавшийся. Планировщик и сервис отправки проверяют этот признак, в том числе перед обработкой уже поставленного в очередь письма. Уже переданные почтовому серверу письма отозвать нельзя.

Отписка не требует входа в аккаунт. Ссылка не оборачивается в трекинг маркетинговых переходов. Для прямой отправки через API связывайте сообщение с контактом: используйте contact_id либо адрес уже существующего контакта в этом рабочем пространстве.
