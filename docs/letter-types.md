# Типы писем

В разделе «Редактор письма» над названием шаблона есть переключатель:

- **Персонализированное** — подстановка известных данных контакта (имя, компания, дополнительные поля). Старые шаблоны открываются в этом режиме.
- **Общее** — одинаковая тема и текст для получателей. ФИО не требуется: контакт может содержать только email. Адресатов выбирают при создании рассылки, не в предпросмотре.

Для нового общего письма заполните тему, тематический заголовок в начале письма и основной текст. Автоматическое приветствие не добавляется. Кнопка «Заголовок» на панели редактора позволяет менять формат выбранного абзаца.

При переключении существующего письма текст, CTA, фотографии и видео сохраняются. Если в общем письме остались персональные переменные, приложение показывает предупреждение и блокирует проверку/сохранение, пока вы не замените их обычным текстом или не вернётесь в персонализированный режим. Разрешена общая переменная `{{product_name}}`; она одинакова в рамках одной кампании.

Нажмите «Сохранить шаблон». Выбранный тип виден в библиотеке и сохраняется при повторном открытии, создании копии и восстановлении версии. Сохранение и переключение не запускают рассылку и не меняют уже созданные цепочки. Служебные ссылки отписки и отслеживания при отправке могут различаться для адресатов.

Технически тип хранится в `editor_state.attrs.letterType` (`personalized` / `general`). Отсутствующее значение означает `personalized`. Сервер проверяет тему, HTML и текст общего письма, не полагаясь только на ограничения интерфейса.
