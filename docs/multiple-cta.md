# Несколько кнопок со ссылками

1. Поставьте курсор в нужное место письма и нажмите **+ CTA**.
2. Введите текст кнопки и полный URL с `https://` или `http://`, нажмите **Вставить CTA**.
3. Повторите для следующих кнопок. **+ CTA** всегда создаёт новую кнопку, даже
   если другая выделена; в этом случае новая вставляется после выделенной.
4. Чтобы изменить существующую, нажмите её в тексте, затем **Изменить кнопку**
   на панели. Меняются только её текст и ссылка.
5. Перетаскивайте кнопку за **⠿** в нужное место текста. На телефоне или с
   клавиатуры выделите кнопку и используйте **↑ Выше / ↓ Ниже**: один шаг —
   соседний блок текста или другая кнопка в том же контейнере.
6. **Удалить кнопку** убирает выбранную. **Отменить действие / Повторить действие**
   восстанавливают изменения; каждое перемещение стрелкой — отдельная операция.
7. Нажмите **Проверить письмо**, проверьте ссылки в HTML-предпросмотре и сохраните
   шаблон. Кнопки сохраняются в выбранном порядке с независимыми ссылками.

В редакторе нажатие выделяет кнопку, а не открывает сайт. В готовом HTML-письме
получатель видит кликабельные кнопки без служебных элементов перемещения.
Позиционирование идёт в потоке текста, без наложения поверх текста и абсолютных
координат — это сохраняет совместимость с почтовыми клиентами.

Старые шаблоны совместимы, миграция не требуется. Серверный компилятор уже
обрабатывает несколько `ctaButton`; формат JSON не изменён.

Использован штатный механизм [перетаскиваемых React Node Views Tiptap](https://tiptap.dev/docs/editor/extensions/custom-extensions/node-views/react).

Проверки: `frontend/e2e/multi-cta.spec.ts` (desktop/mobile, перетаскивание мышью,
перемещение стрелками, undo/redo, сохранение, повторное открытие, разные ссылки)
и `tests/test_editor.py` (реальный HTML/text-компилятор и порядок кнопок).
